📦 SAO LƯU & KHÔI PHỤC DỮ LIỆU CLOUDFLARE D1

📦 Sao Lưu Dữ Liệu Toàn Diện (.json)

Tải toàn bộ cơ sở dữ liệu Cloudflare D1 (gồm 14 bảng: Bệnh nhân, Lịch trình, Nhân sự, Chấm công, Thống kê, Tài khoản...) về máy tính để cất giữ an toàn.

Hệ thống sẽ hiển thị thông báo góc dưới màn hình nhắc bác sĩ sao lưu khi đến hạn.
💻 Sao Lưu Bằng Lệnh Command Line (D1 SQL Export)

Chạy lệnh PowerShell trong thư mục backend/ để xuất trực tiếp file SQL từ Cloudflare D1:

cmd /c "npx wrangler d1 export pmcg-db --remote --output=backup_d1.sql"
